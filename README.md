# 가상 소비함 PWA

GitHub Pages에 올릴 파일:
- index.html
- manifest.webmanifest
- sw.js
- icons 폴더

## GitHub Pages 배포
1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더 안의 파일을 전부 업로드합니다.
3. 저장소 Settings → Pages로 들어갑니다.
4. Branch를 main / root로 선택하고 Save합니다.
5. 만들어진 주소를 Chrome 또는 삼성 인터넷에서 엽니다.
6. 브라우저 메뉴 → 홈 화면에 추가 또는 앱 설치를 누릅니다.

기록은 현재 사용한 기기와 브라우저의 저장공간에 보관됩니다.
브라우저 데이터를 삭제하거나 다른 기기에서 접속하면 기록이 자동으로 옮겨지지 않습니다.
